Case 3: Radix UI Select

The same address form, with a @radix-ui/react-select dropdown for the country. Radix renders its own visually hidden native <select> inside the form, so this crashes like case 1.

Add ?no-select=1 to render the form without the Radix dropdown as a control, or ?container=1 for case 5, which puts a container-type: inline-size container query on the form.

React 18 and @radix-ui/react-select 2.0.0, loaded from esm.sh. No build step. All cases
